## Development

Prerequisite: [mise](https://mise.jdx.dev/)

Run:

```bash
mise install # install deps used (odin, sdl, cmake, etc.)

mise run setup # sets up SDL3 on machine for project

mise run dev # starts the dev app (hot-reload capabilities)
```
